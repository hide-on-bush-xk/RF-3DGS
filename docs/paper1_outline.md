# 论文 1 大纲(草案,2026-09-19):RRF 的重建质量由什么决定——一篇锚在 RF-3DGS 上的受控测量

定位:不是"更快的方法",是"测了 RRF 质量究竟由什么决定"。锚点是 C0(发布数据 + 发布 checkpoint 复现 15.97 vs 16.02),
所有变量在同一场景、同一仿真器、同一评估上逐个受控地动。它刻画 RF-3DGS,不批评它。
每个数字带:数据规模、GPU、是否独占、seed 噪声底(0.03 dB)。文献定位见 literature_check.md(已按协议核对)。

## 1. 引言

- RRF(RF-3DGS、WRF-GS、GSRF、RF-PGS、BiWGS、RxGS)都在改表示;没有人问过:在表示之外,重建质量由哪些数据与度量因素决定。
- 三个主张(各自有数):(i)跨视角一致性是支配因素,超过编码域与几何自适应;(ii)几何适配是低维、分布式、Tx 专属的;(iii)常用指标看不见物理。
- 贡献列表 + 锚点声明(C0)。

## 2. 锚点与实验协议

- C0:发布数据、发布 checkpoint、gsplat 复现(15.97 / 16.02);为什么需要锚点——RF-PGS 报的 RF-3DGS 基线 14.22 是在不同条件下重跑的(其 Table I 为多配置平均),
  与其 20.61 不可与我们的 21.53 横比;我们有锚点,他们没有。
- 流水线:Sionna 2.1(GPU)→ 六种谱 → 4 面针孔 → gsplat 训练;每一层的输入输出;评估 = 物理解码指标优先(方位/天顶/时延中位、P90、RMSE),dB RMSE,范围内 RMSE;PSNR 只作兼容。
- 报告契约:全链计时、独占 GPU、中位数、≥2 个分辨率、as-published / + 工程修正两行、MISSING 不省略;smoke 优先。

## 3. 跨视角一致性(主线)

- 机制:alpha 合成假设同一物理场被各视角一致地观测。三个受控实例、一张表:
  逐图归一化(辐射一致性,PSNR 18.15 → 11.97);逐视角 RT seed 在路径级目标上(几何一致性,功率 RMSE 12.67 → 8.57,−32%);
  同一 seed 差异在波束谱(MVDR)上**量不到**(18.75/3.91 vs 18.69/3.94,噪声底内)——界定适用范围:代价取决于目标是路径级溅射还是阵列统计量。
- 比较:几何解冻 −27%、编码域 db vs rgb(每个设置都赢但幅度小)、通道拆分(方位接缝 3.2×,只伤自己的通道)。
- 教程实现在三个独立位置违反了它;竞品无人检查数据生成的一致性。

## 3b. 评测协议:地板、密度、外推(新)

- 地板:最近邻拷贝 / 两近邻插值 / 常数预测,与 RRF、真值上限并列;随机 20% 留出的最近训练位置只有 0.23 m,是不现实的密度。
- 密度扫描(800 → 20 个位置):拷贝线性劣化(1.07° → 4.68°),场平坦(0.59° → 0.78°);交叉点方位 < 0.23 m、天顶 ≈ 0.3 m、时延 ≈ 0.6 m。
  可引用:"测量间距超过 ~0.6 m,场在三个通道上优于最近邻查表"——竞品无人测过。
- 留一区域(走廊尽头,1.4–2.8 m 无训练点):方位 1.47° vs 拷贝 7.38°,天顶 1.99° vs 4.29°;论文"外推到未访问位置"的主张第一次有数。
- 波束选择 top-k:M=10 可用(top-1 0.68,top-3 功率加权 0.91),64×64 不能做 top-1(0.19,σ=1);5.94° 的适用阵列规模需明确(64×64 上是 3.7 个波束宽)。

## 4a. 方法:时延 = 解析范围 + 学习残差(唯一由测量逼出的算法改动)

- 地板实验:时延通道比抄邻居差 3×(2.42 vs 0.86 ns)。机制:τ = τ_scatter + |p − μ|/c,范围项是距离,方向性 SH 表示不了。
- 修法:gsplat 原生渲染 Σw·d,除以 c 加到时延通道;20 行。结果:中位 0.95 ns(2.5×)、P90 6.6(1.9×)、功率加权中位 0.40(9×,与拷贝持平);其它通道不变。
- 文献位置:RF-PGS 用解析路径长做幅度;时延通道是 RF-3DGS 独有,BiWGS/RxGS 不编码——解析 + 残差用到时延上没人做过。

## 4. 几何:谁承载增益,它能搬多远

- 解冻 −27%(18.75/3.91 → 21.53/2.85);位移毫米级,变的是尺度/朝向;冻结重拟合相同 → 不是联合训练伪影。
- 24/76 分解(A→B 搬运 vs B 自身解冻);power 模式相同增益 + N_eff 6–8 → 不是 dB 混合偏差;C→B 有害 → 不是通用容量。
- 子集:随机 1% 拿 73%、3% 84%、11% 94%;碟 11% 99%、针 40% 93% → 形状类别不是变量,自由度才是(与 RF-PGS 的平面基元理据相对)。
- 转移曲线(10 源,2k 预算校准,噪声底 0.03 dB):二元结构——同侧全正(均 +0.33)、跨区全负(均 −0.20),与距离无关;平台 −0.46 dB;指数 d_c 只作参考(自助 2–40 m)。
  GRaF 假设"邻近可近似",我们给出条件:照亮同一批表面。
- 参数空间 PCA:10 组增量近乎正交(5 个主成分 66%),平均增量 26% ≈ 功能上的 24%;系数插值不比平均好 → 部署结论:视觉几何 + 每 Tx 1–3% 的增量。

## 5. 指标看不见物理(四个实例)

- 材料电导率错 10^18(近 PEC):PSNR 不动,多跳份额均值 13.7% → 31%(2.3×)。
- 发布数据 2.4 GHz vs 论文 60 GHz(34 dB):同一套 PSNR 论述照样成立。
- 多跳份额:depth-1 孪生在走廊尽头漏 23–82%,PSNR 不可见;按接收功率分层,不按 LoS 存在性。
- σ:极小点随度量的权重移动(按像素 1–2°,按功率到网格极限 0.33°,天顶反向)——超参由指标决定;方位/天顶不对称的几何机制(AoA 仰角分布,round 12)。
- 因此主指标改为解码后的物理量;PSNR 只作兼容。

## 6. 成本(按契约)

- 一次 Tx 换位的全链:生成 + 训练 + 评估,分项;as published(0.19/TF CPU,0.9 h)、+ 工程修正(8.2 min)、本工作 800 位置(8.6 min)、160 位置(1.7 min);"教程 + 只加批处理"MISSING。
- 光栅器两个分辨率以上;工程/方法分解;对手:RF-PGS 全训 3 min 53 s(同场景)、高斯上的 RT 零重训。

## 7. 边界与未做

- 单场景、合成数据(两个频率、两套材料);MCMC 未配好;端到端可微只在 roadmap;fisheye 未做;联合训练共享基底未做(参数空间 PCA 只否定"从独立适配白拿基底")。
- 60 GHz 与 2.4 GHz 的多跳份额分层给出 depth-1 的适用范围。

## 8. 结论

- 一句话:在 RF-3DGS 的设定里,数据生成的跨视角一致性对重建质量的影响(−32%、−6.2 dB)大于任何表示层的改动;几何适配是低维、Tx 专属、方向性的;常用指标看不见这些。
