# 给 Hu 的一页:RF-3DGS 复现里发现了什么(2026-09-19)

## 锚点

- 发布数据 + 发布 checkpoint,在 gsplat 上复现:PSNR(jet) **15.97 vs 论文 16.02**。所有后续实验在同一场景(NIST 大堂)、同一仿真器(Sionna 2.1)、同一评估上受控地动一个变量。
- 发布数据是 **2.4 GHz** 的(`cbf_power.csv` 与 2.4 GHz 计算值差 1.6 dB,与 60 GHz 差 34 dB);教程材料的电导率公式有单位错误(频率除以 1e-9),ITU 类材料全成了完美导体。两条都不影响 PSNR。

## 主发现:跨视角一致性支配重建质量

alpha 合成假设同一个物理场被各视角一致地观测。教程实现在三个独立位置破坏了它,各自有数:

| 违反方式 | 破坏的是 | 实测代价 |
| --- | --- | --- |
| 逐图归一化 | 辐射一致性 | PSNR 18.15 → 11.97(−6.2 dB) |
| 逐视角随机采样散射路径(每个视角自己的 seed) | 几何一致性:同一位置四个面看到不同的路径集合 | 功率通道 RMSE 12.67 → 8.57(**−32%**) |
| 同一 seed 差异,作用在 MVDR 波束谱上 | 同上 | **量不到**(18.75/3.91 vs 18.69/3.94,噪声底 0.03 dB 内) |

对比:几何解冻(位置/尺度/朝向可训练)带来 −27%;编码域 dB vs RGB 在每个设置都赢但幅度小。**对路径级目标,数据生成的一致性比任何表示层的改动都大;对阵列统计量(MVDR 谱)它量不到——代价取决于目标的类型。**

## 与已有工作的关系(逐条核对过原文)

- 发布的 RF-3DGS 管线按构造带有第二条(教程全局 seed 一次,每次 `compute_paths` 按 `scat_keep_prob` 随机保留散射路径,相邻视角抽到不同子集)。
- RF-PGS(Zhang, Li, Sun,2508.16849;同一个大堂、同一仿真器)的生成细节未公开(代码待接收后放出);论文给的是截断阈值和全景查询,seed 与归一化未说明——**不能判断它是否受影响**。它报的 RF-3DGS 基线 14.22 dB 比发布 checkpoint 的 16.02 低,是不同条件下的重跑。
- BiWGS / RxGS / GS-CG / GRaF 都在改表示或条件化;没有人检查数据生成的一致性。

## 其它可写的量化结果

- 几何适配是低维、Tx 专属、方向性的:随机 1% 的高斯解冻拿到 73% 的增益;10 个源 Tx 的转移曲线是二元的(同侧 +0.33 dB,跨区 −0.20 dB,与距离无关),远处适配的几何比原始几何差 0.46 dB;10 组几何增量近乎正交。
- 指标看不见物理:材料错 10^18 而 PSNR 不动、多跳份额偏 2.3×、σ 的最优值随度量移动。主指标改为解码后的物理量(方位中位 0.6°、天顶 0.9°、时延 2.4 ns)。
- 一次 Tx 换位全链 65 s(160 位置,生成 + 训练),按报告契约计时。
