## 3. 诊断:训练位置上为什么只有约 42 %(只读分析,2026-09-25,无新训练)

Ke 怀疑学习算法本身不对。做法:6 个 agent 分别读输入、模型、渲染、目标、指标、历史,模型 / 渲染 / 目标三路各由另一 agent 逐条对代码核实
(107 条:65 确认、24 部分对、0 错);关键的新数字再由 3 个 agent 独立复现并设法推翻。只用 CPU 读已有的数据和 §2 的训练结果。
脚本与原始输出:`output/cluster/analysis/2026-09-25_physics_vs_model/`(不进 git)。

**现在的设定(已核实)**:输入 = 一个接收位置的 4 个针孔面(各 300 × 200、90° × 67°,只覆盖仰角 ±34°);目标 = 每面的 APS(dB,
全局 79 dB 跨度归一化到 [0, 1]);数据里一个像素 = 从这个方向到达的所有路径功率之和(非相干、路径间无遮挡、最多一次反弹、1° 高斯核)。
参数 = 视觉 3DGS 的 1,014,142 个高斯,几何冻结,每个只训 17 个数(不透明度 + 一个 SH3 标量值,只随"接收机 → 高斯"的方向变,不含距离、
不知道发射机);渲染 = 线性功率从前往后 alpha 混合后取 dB;loss = 0.8 L1 + 0.2 (1 − SSIM),在归一化 dB 上逐像素,4 面平均,Adam,学习率恒定。

**发现(均为测量,已独立复现)**:
1. **42 % 是两类面的平均**:每个位置最亮的面 85 %(比留一法最近邻抄谱 55 % 还好);其余三面(比最亮面低 26–54 dB,占计分视图的 2/3)
   只有约 21 %。四个 dir-loss 臂都没动后者;ce 的 +2.6 全在最亮面上(84.5 → 93.0 %)。
2. **主峰的物理**:160 个训练位置的 distinct 视图里 74 % 的主峰在直射或发射机的一阶镜面镜像 1° 以内。最亮面 100 %(22 % 直射 +
   78 % 东墙 x ≈ 8.48 的镜像;发射机的 tr38901 天线朝 +x,离东墙 1.58 m,大多数接收机在它背后)。其余三面约 60 % 是镜像(主要是
   西墙 x ≈ −4.70、南墙 y ≈ −10.8,反射损耗 −9 至 −12 dB,与 Fresnel + 散射系数 0.7 相符),其余约 26 % 是更宽、更弱的峰,像漫散射或面边缘。
3. **模型为什么学不会这些镜像**:镜像在视线方向上约 16.5 m 深,而这条视线上的可见表面约 5 m;冻结的几何在西墙、南墙的镜像点附近
   1.5 m 内一个高斯都没有,模型只能把功率"画"在墙面高斯上。但接收机一动,亮斑就在墙上滑动:1 m 内的邻近训练位置从墙面高斯看只差

## 4. 信息量阶梯:第一步(不训练)的测量方案,判据于 2026-09-26 跑之前写下

Ke(2026-09-26):在每个环节测量信息量,找出哪个环节丢了收敛路径(采样、参数、目标、表示)。方案全文另见 Ke 的 Claude 文档
"RF-3DGS 信息量阶梯";这里是同一份判据。做法:上界阶梯,每级把一个环节换成理想版本,同一批视图、同一指标上计分,相邻两级之差
= 该环节的损失。两个单位,都按面拆开(最亮面 = 每个位置含整圈最大值的面;暗面 = 其余三面):任务指标(主峰 ≤ 1°,正式定义)和
方向信息量 b = log2(Ω_ring / Ω_cap(max(ε, 1°))),Ω_cap(ε) = 2π(1 − cos ε),Ω_ring = 4 个面的像素立体角之和(约 6.45 sr),满分约 12.7 bit;
均匀随机猜的期望值另算,作零点。

共同设定:160 个训练位置的 640 张视图,distinct 464 张(最亮面 152、暗面 312);几何 = 视觉 3DGS 的 1,014,142 个高斯,"表面" =
不透明度 ≥ 0.5;峰值表面点 S = 每张 distinct 视图真实主峰射线 0.5° 内的第一个表面高斯(找不到的单列"无表面");观测者 j = S 落在
训练位置 j 的某个面内、且 j → S 线段 5 cm 内没有其他表面高斯(S 附近 10 cm 除外);要求值 d_j = j 的真值在 S 所在像素的 dB。

- **M1 换算与拆分**(15 个容量 run、留一法最近邻〔池 = 其余 159 / 466 个位置〕、镜像几何预测器):按面报 ≤ 1°、ε 中位数、平均 bit、零点。
  校验:≤ 1° 必须与已报的数一致到 0.1 个点(base 均值 41.7 %、最近邻 38.1 % / 59.5 %、预测器 66.6 %),否则是实现错误。
- **M2 可观测性(L1)**:每个 S 的 n_obs、观测方向张角、SH3 可定系数数(设计矩阵奇异值 ≥ 最大值 1 % 的个数)。暗面峰值点 n_obs 中位 ≥ 16
  且可定系数中位 ≥ 12 → 训练位置上的失败不是采样不足;n_obs 中位 < 16 或可定系数中位 < 8 → 欠定,失败指向目标或优化。预测:足够多。
- **M3 带宽需求(L2)**:A = 峰所属的观测者;从 S 看角度最近的 5 个其他观测者(≥ 0.5°),r = 中位数 of max(d_A − d_j, 0)/θ_j(dB/°);
  L_need = ⌈r / 0.691⌉(值域 [0, 1] 的 L 阶函数每弧度最多变 0.5 L,Bernstein;× 79.2 dB)。最亮面峰值点预期 ≥ 70 % 的 L_need ≤ 3。
  暗面分档 ≤ 3 / 4–6 / 7–10 / > 10:≥ 50 % 需 L ≤ 6 → 加参数可行(第二步加 SH6 臂);≥ 50 % 需 L > 10 → 表示不对;其间 → 两者都测。
  预测:暗面镜像点多数 > 3。限制:Bernstein 上限对未截断函数成立。
- **M4 目标对齐(L3)**:n_obs ≥ 20 的 S,SH3 拟合要求值:(a) L1、(b) L2、(c) 峰加权 L1(A 的权重 = 其余之和);报峰值亏缺 δ = d_A − 拟合(A)
  与其余观测者误差中位数。≥ 50 % 暗面点 (c) 使 δ ≤ 3 dB 且其余误差比 (a) 多 ≤ 3 dB → 目标可修;≥ 50 % 暗面点 (c) 仍 δ ≥ 10 dB → 表示受限。
  预测:表示受限。此为对模型有利的理想化(S 独自决定其像素,忽略混合)。

落在预期范围外 = 先查测量假象再报告,不改判据。脚本 `rrf_gsplat/cluster/ladder_step1.py`,输出 `output/cluster/ladder/step1/`。

**M4 补充(2026-09-26,写脚本时发现,任何结果出来之前)**:A 的权重等于其余之和时,加权 L1 的最优解几乎总是精确穿过 A,δ 恒接近 0,
上面"表示受限"的判据(δ ≥ 10 dB)几乎不可能触发。增补:≥ 50 % 暗面点 (c) 使其余观测者误差中位数比 (a) 多出 > 3 dB,也判表示受限
(修回峰就要毁掉邻居)。原两条判据照报。

## 9. 从预测频谱选波束的规则(判据于 2026-09-26 跑之前写下)

**规则 D(波束感知)**:把预测频谱当成各方向的非相干功率,构造它对应的阵列协方差 R̂ = Σ_像素 P(像素) a(像素) a(像素)ᴴ(a 用 t4_score 的同一阵列流形,
含单元方向图),选使 aᴴ R̂ a / |a|² 最大的像素方向作波束;在真实信道协方差上计波束增益损失(同 t4_score)。所有方法(真实频谱、查表、各个场、组合)
都用同一规则。脚本 `rrf_gsplat/cluster/val_beam_aware.py`。
**对照(冒烟)**:(1) 解析解:只含一条路径(一个 1° 高斯斑)的频谱,规则 D 选出的波束在该路径方向 1 像素内;(2) 真实频谱用规则 D 后,波束增益损失的 P90
必须明显低于取主峰时的 10.30 dB(下降 ≥ 2 dB),中位不高于 0.55 dB + 0.1。两条都过才看其他方法。
**读法**:D-T1:某个方法在规则 D 下的波束增益损失中位与 P90 都不高于所有查表在规则 D 下的最好值(各 + 0.1 dB 容差),且 val distinct ≤ 1°(取主峰,
方向指标不变)≥ 最好的查表 + 3 个点 → "两项都胜过查表";否则分别报告。与 G1 比仍用 §12 规则(3 个 seed)。

**§9 第一版的结果(作业 600656):对照没有全过,按规矩停下,其他方法没有计分。** U1 通过(5 个单路径频谱,选出的波束都恰在路径像素上,误差 0)。
U2 不通过:真实频谱用规则 D 后 P90 10.30 → 8.17 dB(降 2.13,够 2 dB),但中位 0.55 → 1.13 dB(超过 0.65 的上限)。
**原因(找到,属于实现错误)**:这个数据集的频谱与真实信道协方差都按各向同性接收单元生成(`rx_pattern: iso`;t6 的协方差由路径响应直接构成);
在真实协方差上做波束扫描时单元方向图在分子分母中约掉,所以 t4_score 的计分不受影响;但规则 D 构造 R̂ 时用了含 TR 38.901 单元方向图的阵列流形,
等于给频谱多乘了 |g|²(面板角上最多约 −9 dB),把波束系统性地拉向面板中心。
**第二版(跑之前写下)**:R̂ = Σ P(像素) s(像素) s(像素)ᴴ,s 是不含单元方向图的导向矢量(rf_spectra 的 `steering`),其余与第一版相同;
对照 U1、U2 与读法 D-T1 一字不改。第二版的对照都过了才计分其他方法。
